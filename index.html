02. Projects

Security Operations · Homelab

Wazuh SOC Homelab

A self-hosted Security Operations Center built on Proxmox to practice threat detection, log analysis and incident response end to end. Wazuh acts as the SIEM/XDR, collecting and correlating telemetry from Windows and Linux endpoints, with simulated attacks used to validate detections.

What I built

  • Deployed Wazuh manager, indexer and dashboard on a Proxmox VM
  • Enrolled Windows and Linux endpoints with Wazuh agents
  • Integrated Sysmon for detailed Windows process and network telemetry
  • File Integrity Monitoring on critical system and web directories
  • Vulnerability detection and CIS benchmark (SCA) assessments
  • Custom decoders and rules mapped to MITRE ATT&CK
  • Active response to automatically block brute-force source IPs

Detection scenarios tested

  • SSH and RDP brute-force attempts
  • Malicious PowerShell and suspicious process execution
  • Unauthorized file changes and new user creation
  • Port scans and reconnaissance from an attacker VM
